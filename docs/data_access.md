# Related datasets and separately held inputs

| Dataset | Persistent access | Use |
|---|---|---|
| Published UC single-cell atlas | https://singlecell.broadinstitute.org/single_cell/study/SCP3755 | Discovery fibroblast/neutrophil states and programs |
| TAURUS, version 3 | https://doi.org/10.5281/zenodo.14007626 | Independent human fibroblast and longitudinal comparisons |
| UC Xenium study | https://singlecell.broadinstitute.org/single_cell/study/SCP3818 | Independent spatial observations |

Associated publications: https://doi.org/10.3389/fimmu.2026.1705328 and https://doi.org/10.1038/s41590-024-01994-8. Follow the original providers' access and reuse terms. Full original third-party datasets are not re-deposited here; selected derived summaries retain their study provenance.

Original sequencing reads, complete Seurat/AnnData objects, FCS files, whole-slide images, original histology acquisition files and model resources are held separately. They are needed for acquisition-level validation and full upstream reconstruction. The manuscript analysis-code repository is https://github.com/GubatanLab/UC-fibroblast-neutrophil-manuscript. This release includes derived tables and analysis workflows; access to separately held raw inputs is not granted by the code or data licenses.
